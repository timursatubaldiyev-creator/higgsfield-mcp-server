# Меридиан — сайт туристического агентства

Полноценный сайт турагентства: каталог туров и стран, горящие туры, скидки,
отели с внешними рейтингами (Tripadvisor/Booking), отзывы туристов, партнёры,
живая погода по сезонности направлений, бонусная программа и личный кабинет
туриста с накоплением баллов. Плюс простая админ-панель для самостоятельного
наполнения контента.

## Возможности

1. **Каталог туров и заявки** — фильтр по направлению, форма заявки с
   предпочтениями (страна, бюджет, даты, кол-во человек) и контактами.
2. **Название и контакты агентства** — в шапке и в разделе «Контакты».
3. **Страны и направления** — карточки стран с описанием и сезонностью.
4. **Отзывы туристов** — как готовые (seed), так и присылаемые через форму
   (проходят модерацию в админ-панели).
5. **Instagram, WhatsApp, Telegram** и другие контакты — в шапке и футере.
6. **Отели** — редактируемый каталог (`data/hotels.json`), можно заполнять
   вручную через админ-панель или напрямую редактировать JSON (в т.ч. скриптом
   с помощью ИИ — формат простой и однородный).
7. **Внешние отзывы** (Tripadvisor / Booking) — рейтинг, число отзывов и ссылка
   на источник у каждого отеля; обновляются администратором вручную, так как
   прямой скрапинг сторонних сайтов нарушает их условия использования.
8. **Партнёры** — авиакомпании, туроператоры, страховые.
9. **Сезонность и погода** — лучшие месяцы по направлению + текущая погода в
   курортном городе (запрос напрямую к бесплатному Open-Meteo API, без ключа).
10. **Горящие туры** — карточки в стиле посадочного талона со скидкой,
    таймером по местам и старой/новой ценой.
11. **Скидки** — отдельный блок с постоянными акциями.
12. **Бонусы туристам** — 5% от суммы завершённого тура зачисляются в баллы.
13. **Личный кабинет** (`/cabinet.html`) — регистрация/вход, баланс баллов,
    история заявок.

## Технологии

- Backend: Node.js + Express, хранение данных в JSON-файлах (без внешней БД —
  просто скопировать `data/*.json` для бэкапа).
- Auth: JWT + bcrypt для туристов, отдельный `ADMIN_TOKEN` для админ-панели.
- Frontend: чистый HTML/CSS/JS без сборки — открывается сразу в браузере.

## Запуск локально

```bash
cp .env.example .env      # задайте JWT_SECRET и ADMIN_TOKEN
npm install
npm start                 # или: node --env-file=.env server.js (Node 20.6+)
```

Сайт: `http://localhost:3000`
Личный кабинет: `http://localhost:3000/cabinet.html`
Админ-панель: `http://localhost:3000/admin.html` (введите значение `ADMIN_TOKEN`)

Если не используете `--env-file`, экспортируйте переменные окружения перед
запуском (`export JWT_SECRET=... ADMIN_TOKEN=...`) — на хостингах вроде
Render/Railway их можно просто задать в настройках проекта.

## Структура данных (`data/`)

- `countries.json` — страны и направления, сезонность, координаты для погоды.
- `tours.json` — туры (в т.ч. горящие, `hot: true`).
- `hotels.json` — отели с удобствами и внешними рейтингами.
- `reviews.json` — отзывы туристов (одобренные показываются на сайте).
- `partners.json` — партнёры агентства.
- `discounts.json` — постоянные скидки.
- `leads.json` / `users.json` — создаются автоматически при первой заявке /
  регистрации, в репозиторий не коммитятся (см. `.gitignore`).

Отредактировать любой из справочных файлов можно вручную (в том числе
сгенерировав содержимое через ИИ по этому же формату) — сервер читает файлы
при каждом запросе, перезапуск не требуется.

## Админ-панель

`/admin.html` — защищена значением `ADMIN_TOKEN` (передаётся как заголовок
`x-admin-token`). Позволяет:

- менять статус заявок и вносить сумму тура — при статусе «Завершена» с
  указанной суммой автоматически начисляется 5% бонусных баллов туристу;
- добавлять/удалять отели, туры, скидки;
- одобрять или отклонять отзывы, присланные через сайт.

## Продакшн-заметки

- Смените `JWT_SECRET` и `ADMIN_TOKEN` на длинные случайные значения перед
  деплоем (`openssl rand -hex 32`).
- JSON-хранилище подходит для старта; при росте нагрузки стоит перейти на
  полноценную БД (Postgres/SQLite) — модели данных уже разложены по сущностям.
- Виджет погоды использует публичный Open-Meteo API без ключа и лимитов для
  небольшого трафика.
